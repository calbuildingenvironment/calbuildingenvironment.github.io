# California Building Environment

A fast, static HTML website for California Building Environment, providing independent environmental inspection and consulting services throughout Southern California.

## Services

- Asbestos Inspections
- Mold Inspections
- Lead-Based Paint Inspections
- Indoor Air Quality Assessments
- Air Monitoring
- Air Clearance Testing
- Environmental Consulting
